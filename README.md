# For My Dearest Aulia ♡

Website ucapan selamat seminar proposal. Statis murni (HTML, CSS, JS), tanpa build.

## Struktur
```
index.html
style.css
script.js
assets/
  music.mp3        (opsional, lagu favorit)
  photos/1.jpg ... 6.jpg   (foto kalian)
```

## Personalisasi
Semua teks yang perlu diganti ada di bagian `CONFIG` paling atas `script.js`:
pesan timeline, 5 alasan, caption & nama file foto, isi surat, dan pertanyaan kuis.

## Hosting di GitHub Pages
1. Buat repo baru, upload semua file (termasuk folder `assets`).
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / root → Save.
3. Buka `https://USERNAME.github.io/NAMA-REPO/` beberapa menit kemudian.

Catatan: musik baru berbunyi setelah tombol "Open Your Surprise" ditekan (aturan autoplay browser).
